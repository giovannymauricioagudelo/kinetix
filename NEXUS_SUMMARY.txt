¿QUÉ ACABO DE CREAR?

Un agente completo, funcionality-rich y production-ready que:
  ✅ Maneja operaciones de BD (SELECT, INSERT, UPDATE, DELETE)
  ✅ Monitorea salud de PostgreSQL + SQL Server
  ✅ Gestiona pool de conexiones
  ✅ Proporciona estadísticas en tiempo real
  ✅ Está documentado automáticamente en Swagger
  ✅ Usa Circuit Breaker para resiliencia
  ✅ Es pronto para escalar a millones de usuarios

================================================================================
LOS 6 ENDPOINTS
================================================================================

Todos bajo: /api/v1/nexus

[1] GET /health
    → Verificar salud de ambas bases de datos

[2] POST /query
    → Ejecutar SELECT contra PostgreSQL o SQL Server
    Body: { "sql", "params", "database", "timeout" }

[3] POST /execute
    → Ejecutar INSERT, UPDATE, DELETE
    Body: { "command", "sql", "params", "database" }

[4] GET /tables
    → Listar todas las tablas de una BD
    Query: ?database=postgresql|mssql

[5] GET /stats
    → Estadísticas de ambas BDs (tamaño, tablas, índices, cache)

[6] GET /connections
    → Estado de los pools de conexión (activas, ociosas, límites)
