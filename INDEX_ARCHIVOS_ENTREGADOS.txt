🚀 INSTALACIÓN RÁPIDA (5 MINUTOS)
═════════════════════════════════════════════════════════════════════════════

1. Copiar archivos:
   cp business_rules.py src/api/routes/
   cp reporting_routes.py src/api/routes/
   cp qa_routes.py src/api/routes/
   cp postgres_integration.py src/utils/
   cp main_COMPLETE.py src/api/main.py

2. Instalar deps:
   pip install psycopg2==2.9.3 pyodbc==4.0.37

3. Crear tablas SQL Server:
   sqlcmd -i reglas_negocio_schema_FINAL.sql
   sqlcmd -i reglas_negocio_ejemplos_FINAL.sql

4. Iniciar API:
   python -m uvicorn src.api.main:app --reload --port 8000

5. Verificar:
   curl http://localhost:8000/health
   curl http://localhost:8000/api/v1/rules/health

6. Explorar:
   open http://localhost:8000/api/docs
